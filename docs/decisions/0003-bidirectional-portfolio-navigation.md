# Decision 0003: Bidirectional portfolio navigation

Date: 2026-09-04

## Decision

Publish the interactive experience as the separate public repository `Ikteder/portfolio-showcase` and connect it bidirectionally with the classic portfolio.

## Why

- Recruiters can enter through either experience and switch without searching.
- The classic site remains optimized for rapid credibility scanning and résumé access.
- The showcase remains free to use richer motion and interaction without destabilizing the primary user site.
- Separate repositories preserve independent deployment and rollback histories.

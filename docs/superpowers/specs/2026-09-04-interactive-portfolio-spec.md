# Interactive portfolio showcase spec

Date: 2026-09-04

## Goal

Create a memorable, employer-facing companion to the primary portfolio. The experience should demonstrate systems thinking through interaction while keeping claims inspectable.

## Design principles

1. Lead with a point of view: ML work continues beyond model accuracy.
2. Turn evidence into interaction: let visitors explore an actual deployment trade-off.
3. Use play to reveal judgment: the decision game rewards constraint-aware choices.
4. Keep the visual language original: high contrast, acid green, technical mono labels, and editorial typography rather than copying the reference site's brand.
5. Preserve trust: label demo results, limitations, and environment dependence.

## Acceptance criteria

- The original portfolio is not modified.
- The site is a standalone static project.
- Visitors can interact with quantization, distribution drift, and deployment trade-offs without leaving the page.
- All controls work with keyboard input.
- Reduced-motion preferences are respected.
- Mobile layouts remain readable and usable.
- Measured values used in the visualization match the source repository.
- Simulation-only visuals are clearly labeled and direct evidence links are available.
